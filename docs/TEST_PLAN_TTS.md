## 一、测试范围

本项目定位为情感陪伴型桌面宠物，使用方式为自然交互对话。TTS 测试聚焦核心体验：

- 基础播放（能出声、声音正常）
- 流式播放（边说边播、不等完整回复）
- 情感跟随（随对话情绪切换朗读语气）
- 暂停/继续（被意外打断后恢复）
- 音色选择（换个喜欢的声音）
- 配置持久化（设置好不用每次重来）
- 服务容错（IndexTTS 挂了不影响聊天）

## 二、环境准备

| 检查项 | 要求 | 验证方式 |
|--------|------|----------|
| 应用已编译 | `cargo build` 通过 | 终端执行 |
| IndexTTS 服务运行 | `http://localhost:9880` 可访问 | 浏览器打开确认 |
| 喇叭/耳机正常 | 系统音量 > 0 | 播放系统测试音 |

| LLM 已配置 | 发送任意消息有回复 | 聊天窗口测试 |

## 三、测试用例

### 3.1 基础体验

#### TC-001: 基础播放

- **前置**: TTS 启用，流式模式关闭，IndexTTS 正常
- **步骤**:
  1. 聊天框输入一条消息，发送
  2. 等待 LLM 回复完毕
- **预期**:
  - LLM 回复完整后 TTS 开始播放
  - 声音清晰，无爆音、无截断

#### TC-002: 流式逐句播放

- **前置**: TTS 启用，**流式模式开启**，IndexTTS 正常
- **步骤**:
  1. 正常发送消息（无需特意构造长文本）
  2. 观察 LLM 流式回复过程中是否逐句触发 TTS
- **预期**:
  - 关键指标：**TTS 在 LLM 输出结束之前就已经开始播放**（不等全部输出完）
  - 每遇 ~~。！？~~ 触发一次播放
  - 如果 LLM 回复较短只有一句，播放至少触发一次

#### TC-003: 首句延迟

- **前置**: 流式模式开启
- **步骤**:
  1. 发送消息
  2. LLM 回复出现第一个完整句子（遇到 。！？）时开始计时
  3. 听到 TTS 播放该句时停止计时
- **预期**:
  - 间隔 < 3 秒（仅计 IndexTTS 提交+合成+下载时间，不含 LLM 网络延迟）

---

### 3.2 情感播放

#### TC-004: Emotion Auto — 情感跟随

- **前置**: TTS 启用，**Emotion Auto 开启**
- **步骤**:
  1. 聊开心的话题（如"今天天气真好，心情很棒"）
  2. 听朗读语气
  3. 聊难过的话题（如"最近有点累"）
  4. 听朗读语气是否变化
- **预期**:
  - 不同情绪话题对应不同的朗读语气
  - 备注：LLM 返回的具体情感值取决于模型判断，只验证"有变化"即可，不强求特定值
  - 若两次情感相同，换个话题再试

#### TC-005: Emotion Auto — 关闭

- **前置**: **Emotion Auto 关闭**
- **步骤**:
  1. 同样聊开心和难过的话题
- **预期**:
  - 两次朗读语气一致（使用默认音色）
  - `<emo>` 标签不会改变播放情感
  - 界面上看不到 `<emo>` 标签

---

### 3.3 播放控制

#### TC-006: 暂停 / 继续

- **前置**: TTS 正在播放
- **步骤**:
  1. 发消息让 TTS 播放（LLM 回复稍长时操作更从容，正常聊即可）
  2. 播放中点暂停
  3. 等几秒后点继续
- **预期**:
  - 暂停后音频立即停止
  - 继续后从暂停处恢复

---

### 3.4 音色与配置

#### TC-007: 获取音色列表

- **前置**: IndexTTS 服务运行
- **步骤**:
  1. TTS 设置页面 → 点击"获取服务器音色"
- **预期**:
  - 3 秒内返回列表，列表非空
  - 若 IndexTTS 不可用，显示错误提示而非崩溃

#### TC-008: 切换音色

- **前置**: 已获取音色列表
- **步骤**:
  1. 选择一个音色，添加并设为默认
  2. 发消息验证新音色
  3. 切回原音色再验证
- **预期**:
  - 不同音色朗读风格有明显区别
  - 切换后立即生效

#### TC-009: 配置重启保持

- **前置**: -
- **步骤**:
  1. 修改以下配置：启用 TTS、调整音量、改变语速、开启流式模式、添加一个音色
  2. 关闭应用
  3. 重启应用
- **预期**:
  - 所有配置与重启前一致，无需重新设置

---

### 3.5 异常处理

#### TC-010: IndexTTS 服务不可用

- **前置**: -
- **步骤**:
  1. 停止 IndexTTS 服务
  2. 发送消息
- **预期**:
  - 聊天功能正常（LLM 回复不受影响）
  - TTS 相关操作有错误提示，不崩溃
  - 重启 IndexTTS 后 TTS 恢复正常
